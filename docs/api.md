# API существующего приложения

Ответ: `{"data": ...}`; ошибка: `{"error": "описание"}` с соответствующим
HTTP-статусом. JSON UTF-8. Заголовок `X-Demo-User: 1` выбирает Анну,
`2` — Бориса, `3` — Веру. По умолчанию 1. Это открытый демо-переключатель,
не доказательство личности; локальный API не предназначен для публикации в сеть.

| Метод и путь | Текущее поведение |
|---|---|
| `GET /api/health` | Проверка запуска сервиса |
| `GET /api/context` | Демо-пользователи, выбранный пользователь, время UTC и дата создания демо |
| `GET /api/projects` | Только проекты текущего пользователя, участники, количество задач и `escalation_count` руководителя |
| `GET /api/projects/{id}/tasks` | Все задачи доступного проекта: сначала задачи с признаком «Нужен руководитель», затем по номеру |
| `POST /api/projects/{id}/tasks` | Создать задачу в активном проекте |
| `GET /api/tasks/{id}` | Доступная задача с комментариями и авторами |
| `PATCH /api/tasks/{id}` | Изменить поля с проверкой версии |
| `POST /api/tasks/{id}/comments` | Добавить комментарий (201, `author` — имя автора) |

Поля задачи для создания и изменения: `title`, `description`, `status`,
`assignee_id`, `due_at`, `escalated`. При создании `title` обязателен.
Неизвестные поля отклоняются. Исполнитель — участник проекта или `null`. Даты —
строго `YYYY-MM-DDTHH:mm:ssZ` либо `null`; текущий UI редактирует их с точностью
до минуты. Для PATCH обязательно целое поле `version`, полученное при чтении.
Успешное изменение увеличивает версию; устаревшая версия возвращает 409.

`escalated` — булев признак «Нужен руководитель». В ответах он приходит как
`0` или `1`, как и хранится в базе. В заметке PATCH меняется только переданный
признак. Завершённая задача (`status: done`) не может требовать руководителя:
явная передача `escalated: true` вместе с `done` возвращает 422, а при
закрытии задачи без упоминания флага сервер сам снимает его (`escalated: 0`).

`escalation_count` в `GET /api/projects` считает только незавершённые задачи с
признаком, виден он руководителю активного проекта (владелец проекта) и равен
нулю для остальных участников и архивных проектов. В карточке задачи текущий
пользователь правит признак так же, как остальные поля.

Метод добавления комментария принимает `{"body":"текст"}`, обрезает пробелы по
краям и сохраняет комментарий от имени выбранного демо-пользователя; пустой
текст отклоняется с 422. Чтение комментариев доступно через карточку задачи.

Максимумы строк в байтах UTF-8: название 200, описание 10000, комментарий 5000.
Максимум тела изменения — 32 KiB. Ошибка валидации — 422, JSON — 400,
неизвестный пользователь — 401, отсутствующий или недоступный объект — 404,
запись в архив — 409. Поиск и фильтр статуса в текущем UI выполняются локально.
